# Golden Crunch — Frango estaladiço

Site responsivo para uma marca de frango frito, com conteúdo em português de Portugal, identidade visual renovada e animações suaves.

## Funcionalidades

- Navegação adaptada a computador e telemóvel, com suporte para teclado.
- Animações de entrada ao percorrer a página e efeitos de interação.
- Respeito pela preferência do sistema para movimento reduzido.
- Seleção de produtos com confirmação acessível no próprio site.
- Layout responsivo para telemóveis, tablets e computadores.

## Executar

Abra `index.html` num navegador. Não é necessário instalar dependências.

Os ícones e tipos de letra utilizam recursos externos; as restantes imagens e funcionalidades estão incluídas neste projeto.

## Nota sobre a demonstração

Adicionar produtos apenas atualiza a seleção temporária nesta página. Não existe checkout, pagamento, envio de encomendas ou recolha de dados pessoais.
